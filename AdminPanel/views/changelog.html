🚀 Overview

Sentinel is a comprehensive, professional-grade solution for Discord server moderation and community management. Explore the latest major updates and feature enhancements below.

NEW Major Update 6.0.0 March 2026
  • Feature Added an email system for notifications and alerts
  • Feature Added a "link discord" system
  • Feature Added an TOTP system
  • Feature Admin Panel: Modernized tab system implemented across all major pages (Admin, Moderator, Owner, Features, Changelog)
  • Enhance Navbar now displays username and account role and functions consistently on all pages
  • Feature Performance: Faster page routing and real-time metric updates via optimized WebSockets
  • Security Global Security: Enhanced role checks and strict permission validation routines
  • Enhance Reworked appeals process and appeal system
  • Bugfix Fixed responsive CSS padding and dropdown menu Z-index overlap issues
  • Feature Added a music system and improved join to create and the commands associated with it
  • Feature Added a "Ghost Ping" feature that notifies users when they are mentioned in a message but the message is deleted shortly after
  • Bugfix Fixed minor UI glitches and improved overall stability
  • Feature Added multiple utility commands such as "avatar", "banner", "birthday"
  • Feature Added new moderation commands such as "audit", "slowdown", "Modlogs"
v5.0.0 Major Update 5.0.0 February 3, 2026
  • Total Redesign: Completely redesigned Admin Panel with a modern tab system and enhanced dashboard modules.
  • Advanced Moderation Suite: Ban, kick, timeout, warn, clear messages, and comprehensive audit logging.
  • Enterprise Support Tickets: Featuring claim management, user addition/removal, status tracking, and transcript logging.
  • Smart Auto-Moderation: Filters for blocked words, spam prevention, invite protection, and DM alerts.
  • XP & Leveling Engine: Customizable XP scaling, leaderboard generation, aesthetic rank cards, and full admin wipe controls.
  • Giveaway Module: Timed giveaways, participant roll tracking, and automatic winner selection.
  • Fun & Utilities: 8ball, trivia, coinflip, reminders, polls, server/user info lookups, crypto tracking, and complete member verification.
