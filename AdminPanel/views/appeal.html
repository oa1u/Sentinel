👤 Account Information

Tell us which Discord account the appeal is for so we can match it correctly.

💡 Use your current Discord username, not your server nickname or display name.

💡 Right-click your profile and copy your User ID. Developer Mode needs to be enabled in Discord.

📧 We use this to send appeal updates and any follow-up notes.

🚫 Ban Information

Enter the ban case ID from your ban message so we can pull up the right record.

💡 You can usually find this in the ban DM you received. It starts with BAN-.

📌 Where to find your Ban Case ID:
• Check the direct message you got when the ban was issued
• Look for a code that starts with "BAN-"
• Example: BAN-kX7mP9qL2n

⚠️ A few things that help your appeal:
• Be honest about what happened. False information can get the appeal rejected outright.
• Show that you understand the rule and why the moderation action happened.
