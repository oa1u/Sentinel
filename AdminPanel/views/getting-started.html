Getting Started

Minimal Launch Guide

This page keeps setup simple: complete the quick start checklist, run the Config Readiness Check, and then continue to the dashboard once everything passes.

~10–15 min Owner/Admin Config + Security First

Quick Start Checklist

4 Stages

Complete these before opening access to your full team.

Estimated Time 10–15 min
Minimum Role Admin / Owner
Goal Ready for controlled go-live
1. Prep 2. Access 3. Security 4. Validate
  • 1 Environment Prep
    Medium Impact
    Confirm bot token, panel secrets, and database credentials are present and non-placeholder.
    • Validate Config credentials keys are set for this environment.
    • Ensure required JSON config files parse and contain expected IDs.
  • 2 Access & Routing
    High Impact
    Verify role visibility and permission boundaries before onboarding moderators.
    • Confirm owner/admin/moderator routes display correctly by role.
    • Confirm unauthorized accounts are blocked from gated pages.
  • 3 Security Baseline
    High Impact
    Lock down privileged operations so incident recovery is reliable.
    • Enable 2FA for privileged panel accounts and store recovery codes safely.
    • Review active sessions and revoke unknown or stale sessions.
  • 4 Operational Validation
    High Impact
    Run readiness + one live workflow to confirm auditability.
    • Run the Config Readiness Check and clear all fail states.
    • Execute one moderation action and verify logging shows actor, target, and reason.
