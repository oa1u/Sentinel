What is this? #

Sentinel is a Discord bot that you host yourself. Unlike those big public bots that are in millions of servers, Sentinel is designed to live in just one place: your server.

Because it's private, you don't have to share resources with anyone else. It's faster, more secure, and you have complete control over every single piece of data it handles.

Why self-host? #

Running your own bot might seem like extra work, but it pays off:

  • It's YOURS: You own the code, the data, and the database. No more worrying about a public bot going down or selling your data.
  • Zero Latency: Since it only serves your community, it responds instantly.
  • Custom Fit: Features are built specifically for the way a single community operates, rather than trying to please everyone.

What can it do? #

  • Keep things safe: Tools to warn, mute, and ban troublemakers.
  • Stop spam: Auto-filters for bad words, caps, and spamming.
  • Help your members: A private ticket system for support.
  • Fun stuff: XP and leveling to keep chat active.
  • Easy management: This dashboard you're looking at right now!

How do I install it?

Setting up your private bot is easier than you think.

Prerequisites #

Before we start, make sure you have these things ready:

  • Node.js v16+: This is the engine that runs javascript. If you don't have it, google "Install Node.js".
  • A Discord Application: Go to the Discord Developer Portal and make a new application. That's your bot!
  • MySQL Database: You'll need a database to store levels and warnings. Setting up XAMPP or installing MySQL server is usually the easiest way.

Setup Steps #

  1. Download the code and unzip it somewhere safe.
  2. Open a terminal in that folder and install the dependencies:
TERMINAL
npm install
  1. Now, let's create the database tables automatically:
TERMINAL
npm run setup
  1. Fill in your secrets (Token, DB password) in Config/credentials.env.
  2. Start the bot!
TERMINAL
npm start
💡
Pro Tip If you're running this on a VPS or server, use something like PM2 so it restarts if it crashes.

Configuring your Bot

Making sure Sentinel knows where its home is.

The Important Secrets #

Open up Config/credentials.env. This is where the magic keys live.
Do not share this file with anyone! It contains your bot token and database passwords.

CONFIG/CREDENTIALS.ENV
DISCORD_TOKEN=put_your_bot_token_here MYSQL_HOST=localhost MYSQL_USER=root MYSQL_PASSWORD=your_db_password MYSQL_DATABASE=discord_bot

General Settings #

Next, check Config/main.json. This is where you tell the bot which server it belongs to. Since Sentinel is private, it needs to know your Server ID (Guild ID) so it can ignore commands from anywhere else.

CONFIG/MAIN.JSON
{ "serverID": "YOUR_SERVER_ID_GOES_HERE", "OwnerID": "YOUR_PERSONAL_ID", "botName": "My Awesome Bot", "PanelEmoji": "🛡️" }
  • serverID: Right-click your server icon and click "Copy ID". Paste it here.
  • OwnerID: Right-click your own profile and copy your ID. This gives you full admin access to the dashboard.

Moderation Tools

Keeping your server clean and friendly.

The Basics #

Most of the time, you'll be using these simple slash commands to manage users:

  • /warn @user [reason]: Adds a warning to their record.
  • /mute @user [duration] [reason]: Time-out a user so they can't type.
  • /kick @user [reason]: Kick them out (they can rejoin).
  • /ban @user [reason]: Ban them permanently.

Tracking Cases #

Sentinel remembers everything. Every time you warn or ban someone, it creates a Case ID. You can look these up later if you forget why someone was banned, or if they appeal.

COMMANDS
/case view [case_id]

AutoMod

Let the bot do the heavy lifting.

Protection Profiles #

Different days call for different rules. You can set up profiles like "relaxed" or "strict". If a raid happens, you can switch to "strict" instantly from the panel to stop the chaos.

What it filters #

  • Spammers: People sending messages too fast.
  • YELLING: Blocks messages with too many CAPS.
  • Bad Language: Automatically deletes words you've blacklisted.
  • Invite Links: Stops people from advertising other servers.

Leveling System

Give your active members some shine.

People love seeing numbers go up. Users earn XP just by chatting. You can control how fast they level up and add a cooldown so people don't spam just for points.

Rewards

You can set it up so users automatically get a cool role (like "Regular" or "Veteran") when they hit a certain level. Check Config/leveling.json to set the rewards.

Ticket System

Private support channels for your members.

Sometimes users need to talk to staff privately. Instead of messy DMs, they can open a ticket. Sentinel creates a private channel just for them and the staff team.

Cool Features

  • Transcripts: When you close a ticket, Sentinel saves a pretty HTML file of the whole conversation, just in case you need it later.
  • Categories: You can have different types of tickets, ranging from "Low", "Medium", to "High", depending on how important the user thinks the issue is.

Who can do what?

Understanding the roles for this dashboard.

  • Owner: That's you. You can do literally everything.
  • Admin: Your right-hand people. They can change settings and ban people.
  • Moderator: The enforcers. They can warn, mute, and handle tickets, but they can't break the bot settings.

Help! It's broken!

Common problems and how to fix them.

The Big One #

⚠️
Remember Sentinel is a private bot. It only works in the server ID you put in the config. If you invite it to a second server, it will just sit there and ignore everyone.

It's online, but ignoring me? #

If the console says "Bot is ready!" but commands aren't working:

  • Check Intents: Did you enable "Privileged Intents" (the toggles) in the Discord Developer Portal? You need those.
  • Check Roles: Is the bot's role above the person you're trying to ban? It can't moderate people higher than itself.

Where are my slash commands? #

Sometimes Discord takes a minute. Since Sentinel registers commands instantly to your specific guild ID, they should be there. Try restarting the bot. If that fails, kick the bot and re-invite it.
