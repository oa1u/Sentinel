🔐 Security Overview

Core controls are grouped below for quick scanning and safer operations.

🧩 Session Security
Sessions are encrypted and stored in MySQL, with idle timeout + absolute expiry, and optional single-session enforcement.
🔑 Password Security
Passwords are hashed with bcrypt (10 rounds) and strong password requirements are enforced.
🚦 Rate Limiting
Login is limited to 3 attempts per minute, with IP lockout after 5 failed attempts in 30 minutes.
